# Upgrading to an Approved AquaVaults Integration

The AquaVaults Public Swap Widget is available for public website integrations, but swaps made through the public widget are **not eligible for AquaVaults Rewards**.

If your project later becomes listed or otherwise approved for an AquaVaults integration, listing alone does not automatically change the widget already installed on your website.

## What changes

1. **Contact AquaVaults with the exact production website origin** that will host the approved widget.
2. **Complete the approved integration setup** supplied by AquaVaults for that website.
3. **Replace the public-widget integration with the approved integration** after AquaVaults confirms the site is ready.
4. **Use the exact lowercase listed community ID** supplied for your community.
5. **Test the approved widget on the production origin** before announcing Rewards eligibility.

## Important

Do not represent Public Swap Widget activity as AquaVaults Rewards-eligible activity.

Do not assume that listing a community, changing the `community` option, or locking the community changes the public widget into an approved integration.

The public and approved integration paths are intentionally separate. AquaVaults must approve the website origin and the site must use the approved integration path before applicable widget activity can participate in the approved Rewards flow.

Normal AquaVaults Rewards rules and qualification requirements still apply after an integration is approved.
