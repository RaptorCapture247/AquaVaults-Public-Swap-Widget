# Security Policy

This repository contains public integration documentation and example code for the AquaVaults Public Swap Widget. It does not contain the hosted AquaVaults SDK source code or private AquaVaults backend credentials.

## Reporting a Vulnerability

Please do **not** publish suspected vulnerabilities, exploit steps, private credentials, or other sensitive security details in a public GitHub Issue.

Use GitHub's private vulnerability reporting for this repository.

When reporting, include enough information to reproduce and evaluate the issue, such as:

- the affected page, example, or integration path;
- the browser/wallet environment when relevant;
- clear reproduction steps;
- the security impact you observed;
- transaction signatures or public blockchain references when they are necessary and safe to share.

Do not include private keys, seed phrases, wallet recovery material, API keys, or credentials.

## General Integration Problems

For ordinary documentation errors, broken examples, feature questions, or non-security integration problems, use the repository's public GitHub Issues.
